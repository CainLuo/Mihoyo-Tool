# 材料计算功能 v2.0.0 - 需求文档

## 一、功能概述

为米悠悠工具 App 新增材料计算功能，帮助玩家计算角色和武器养成所需的材料数量，并显示当前背包拥有量与缺口的对比。

### 1.1 核心需求

1. **数据库扩展**：新增 `material_bag` 表存储玩家背包材料数据
2. **API 请求策略**：根据三游戏特性实现不同的请求策略
   - 原神：批量请求（最多 8 个角色/次）
   - 星铁/绝区零：单角色请求
3. **材料汇总**：统一列出所有缺失材料
4. **多入口访问**：
   - 工具 Tab → 游戏入口卡片 → 材料汇总页
   - 角色详情页 → 材料计算卡片 → 单个角色材料计算页

## 二、功能模块

### 2.1 工具 Tab（Tools）

**位置**：底部导航新增「工具」Tab

**功能**：
- 显示三个游戏的材料总汇入口卡片
- 卡片显示角色数量和计算进度
- 支持无账号和无角色数据的空态提示

**验收标准**：
- [ ] 底部导航新增「工具」Tab，图标使用 `sys.symbol.wrench_and_screwdriver`
- [ ] 工具页显示三个游戏入口卡片（原神/星铁/绝区零）
- [ ] 卡片显示游戏名称、角色数量、计算进度
- [ ] 无账号时显示空态提示和登录按钮
- [ ] 有账号但某游戏无角色时，该游戏卡片置灰并显示提示

### 2.2 材料汇总页（MaterialList）

**位置**：从工具页游戏卡片点击进入

**功能**：
- 显示某游戏所有角色的材料汇总
- 支持两种视图模式：按角色分组 / 按材料汇总
- 支持游戏内 Tab 切换（如有多游戏数据）
- 显示材料收集进度和缺口

**验收标准**：
- [ ] 页面顶部显示游戏 Tab（单游戏时隐藏）
- [ ] 支持视图切换：按角色 / 按材料
- [ ] 按角色视图：显示角色卡片列表，可展开查看详细材料
- [ ] 按材料视图：紧凑网格布局，显示材料图标和缺口角标
- [ ] 显示总体进度百分比和总缺口数量
- [ ] 下拉刷新同步最新数据

### 2.3 单个角色材料计算页（MaterialCalc）

**位置**：从材料汇总页角色卡片点击进入，或从角色详情页入口进入

**功能**：
- 显示单个角色的材料需求
- 角色等级目标和武器等级目标可点击修改
- 技能目标设置（普攻/战技/爆发）
- 材料分两个 section：角色材料 + 武器材料
- 下拉刷新

**验收标准**：
- [ ] 角色信息卡显示角色头像、名称、稀有度、等级目标按钮
- [ ] 等级目标按钮可点击，弹出等级选择器
- [ ] 技能目标显示三个技能（普攻/战技/爆发），当前/目标等级
- [ ] 角色材料 section 显示进度百分比和缺口数量
- [ ] 武器材料 section 显示武器图标、名称、等级目标按钮
- [ ] 材料列表显示图标、名称、拥有/需求、缺口
- [ ] 材料充足显示 ✓ 标记
- [ ] 下拉刷新同步数据

### 2.4 角色详情页入口

**位置**：角色详情页内容区域末尾新增「操作」区块

**功能**：
- 显示材料计算入口卡片
- 点击跳转到单个角色材料计算页

**验收标准**：
- [ ] 角色详情页末尾新增「操作」区块
- [ ] 区块包含「材料计算」入口卡片
- [ ] 卡片显示标题和简短说明
- [ ] 点击跳转到材料计算页，自动选中当前角色

## 三、数据库需求

### 3.1 新增表：material_bag

| 字段 | 类型 | 说明 |
|-----|-----|-----|
| id | INTEGER | 自增主键 |
| account_id | TEXT | 米游社账号 UID（外键） |
| material_id | TEXT | 材料 ID |
| material_name | TEXT | 材料名称 |
| material_icon | TEXT | 材料图标 URL |
| rarity | TEXT | 稀有度 |
| count | INTEGER | 拥有数量 |
| source | TEXT | 数据来源（api/manual/computed） |
| game_id | TEXT | 游戏标识 |
| update_time | INTEGER | 更新时间戳 |

**唯一键**：(account_id, material_id, game_id)
**外键**：account_id → account_table.uid (ON DELETE CASCADE)

### 3.2 修改现有表

为三张 Compute 表添加 `raw_json` 字段：
- `genshin_character_compute`
- `starrail_avatar_compute`
- `zzz_avatar_compute`

## 四、API 层需求

### 4.1 原神批量计算 API

- API：`/event/e20200928calculate/v3/batch_compute`
- 方法：POST
- 最大批量：8 个角色（含武器）
- 需要特殊 Header：`x-rpc-cal_type: 1`

### 4.2 星铁计算 API

- API：`/event/rpgcalc/compute?game=hkrpg`
- 方法：POST
- 单角色请求
- 返回 `user_owns_materials` 字段

### 4.3 绝区零计算 API

- API：`/event/nap_cultivate_tool/avatar_calc`
- 方法：POST
- 单角色请求
- 返回 `user_owns_materials` 字段

## 六、非功能需求

### 6.1 性能要求

- 原神 80 个角色批量请求：≤ 10 次 API 调用
- 材料汇总页加载时间：≤ 2 秒
- 数据库查询响应时间：≤ 100ms

### 6.2 兼容性要求

- 支持 HarmonyOS NEXT 6.0.2 (API 18+)
- 支持多账号数据隔离
- 支持三游戏数据独立存储

### 6.3 安全要求

- Cookie 安全存储（已有机制）
- 材料数据按账号隔离
- 外键级联删除保证数据一致性
