# Widget（服务卡片）需求文档

版本：V1.1.0
状态：草稿

---

## 一、背景与目标

在 V1.0 的基础上，V1.1 新增 HarmonyOS 服务卡片（Widget）功能，让用户无需打开 App 即可在桌面、负一屏、锁屏上查看游戏体力数据。

**目标**：

- 支持原神、崩坏：星穹铁道、绝区零三款游戏的体力数据展示
- 支持多账号（每张卡片绑定一个账号，多账号通过添加多张卡片实现）
- 支持桌面、负一屏、锁屏三个位置
- 数据自动刷新（30分钟定时 + 体力变化时主动推送）

### 2.2 各模板显示内容

#### 1×2 迷你（3个独立模板，每个固定一款游戏）

| 模板   | 显示内容                                               |
| ------ | ------------------------------------------------------ |
| 原神   | UID + 体力环 + 原粹树脂数值/上限 + 回满时间            |
| 星铁   | UID + 体力环 + 开拓力数值/上限 + 后备开拓力 + 回满时间 |
| 绝区零 | UID + 体力环 + 电量数值/上限 + 回满时间                |

#### 2×2 标准（游戏数量自动切换）

**单游戏（详细模式）**：

| 游戏   | 基础信息                                | 额外数据（2行）                               |
| ------ | --------------------------------------- | --------------------------------------------- |
| 原神   | 体力环 + 数值 + 回满时间                | 探索派遣（x/5）、每日委托（x/4 + 是否已领取） |
| 星铁   | 体力环 + 开拓力 + 后备开拓力 + 回满时间 | 每日实训（x/500）                             |
| 绝区零 | 体力环 + 数值 + 回满时间                | 今日活跃度（x/400）、刮刮卡/占卜状态          |

**多游戏（精简模式，2-3款）**：每款游戏一行，只显示基础信息（同 1×2 内容）。

#### 2×4 宽幅（游戏数量自动切换）

**单游戏（详细模式）**：左右分栏，左侧体力环，右侧数据行。

| 游戏   | 额外数据（约 4-5 行）                                          |
| ------ | -------------------------------------------------------------- |
| 原神   | 洞天财瓮（x/2400）、每日委托（x/4）、参量质变仪（可用/倒计时） |
| 星铁   | 后备开拓力、每日实训（x/500）、历战余响（x/3）                 |
| 绝区零 | 今日活跃度（x/400）、刮刮卡/占卜状态、录像店经营状态           |

**多游戏（精简模式）**：纵向排列。

- 2款：每款基础信息 + 1行额外数据，右侧显示额外数据
- 3款：每款横排一行（体力环+数值+游戏名·回满时间+右侧第一条额外数据）

#### 4×4 大卡片（游戏数量自动切换）

**单游戏（完整模式）**：

| 游戏   | 完整数据                                                                                             | 特殊说明                                                      |
| ------ | ---------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| 原神   | 洞天财瓮、每日委托、参量质变仪                                                                       | 底部显示探索派遣 5 个角色头像（圆形，5等分，已完成有 ✓ 标记） |
| 星铁   | 后备开拓力（体力区显示）、每日实训、历战余响、货币战争本周积分（x/1000）、模拟宇宙本周积分（x/1000） | —                                                             |
| 绝区零 | 今日活跃度（x/400）、刮刮卡/占卜状态、录像店经营状态                                                 | —                                                             |

**多游戏（精简模式）**：纵向排列，每款游戏一个区块。

- 2款：每款基础信息 + 3行额外数据
- 3款：每款基础信息 + 2行额外数据

## 三、卡片配置（编辑页）

用户添加卡片时，通过编辑页配置：

| 配置项   | 适用范围        | 说明                                       |
| -------- | --------------- | ------------------------------------------ |
| 账号选择 | 所有模板        | 从已登录账号中选择 1 个                    |
| 游戏过滤 | 2×2 / 2×4 / 4×4 | 选择显示哪些游戏，默认全选该账号下所有游戏 |

**编辑方式**：`FormEditExtensionAbility`（半模态面板，从底部弹出）

**步骤流程**：选择尺寸 → 选择账号 → 选择游戏 → 完成

## 四、数据更新机制

### 4.1 更新触发条件

1. **定时刷新**：`updateDuration=1`（每 30 分钟），作为兜底
2. **主动推送**：`StaminaNotificationService` 检测到体力数据变化时，调用 `formProvider.updateForm()` 推送所有相关 formId
3. **首次添加**：`onAddForm` 时立即推送一次初始数据

### 4.2 formId 管理

- `onAddForm`：将 formId + 配置（accountId、selectedGames）存入 Preferences
- `onRemoveForm`：从 Preferences 删除对应 formId
- 主动推送时：从 Preferences 读取所有 formId，遍历调用 `formProvider.updateForm()`

### 4.3 数据传递

- 卡片 UI 通过 `@LocalStorageProp` 接收数据
- 所有数值传递时为字符串类型（Form Kit 限制），卡片内用 `parseInt()` 转换

## 五、App 内入口

在 My 页面新增「添加 Widget」入口区域：

- 根据已登录账号数量动态展示，每个账号对应一组添加按钮
- 点击后调用 `formProvider.openFormManager(want)`，携带 `accountId` 参数
- 用户在系统弹出的卡片管理页选择「添加至桌面」或「添加至负一屏」

---

## 六、锁屏卡片

- 使用 1×2 的三个模板（`widget_1x2_genshin`、`widget_1x2_starrail`、`widget_1x2_zzz`）
- 需配置 `renderingMode: autoColor`
- 需在 AppGallery Connect 申请「锁屏卡片」开放能力（审批 1-3 个工作日）
- V1.1 代码实现，能力审批通过后生效

---

## 七、技术约束

- 卡片 UI 不能 import `core` 模块（HSP 限制），数据通过 `formProvider.updateForm()` 推送
- `EntryFormAbility` 不能 import `StaminaNotificationService`（含 `backgroundTaskManager`）
- 卡片进程与主进程内存隔离，通过 Preferences 共享 formId 和配置数据
- 每张卡片每天最多定时刷新 50 次（`updateDuration=1` 约 48 次/天，在上限内）
- 不同尺寸使用独立的 widget 文件（避免多尺寸数据同步异常）
