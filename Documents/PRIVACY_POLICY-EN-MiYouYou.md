### Collection and Use of Information

All user data in this application (including MiHoYo account Cookies) is stored exclusively on the User's local HarmonyOS device and will not be uploaded to the Developer's servers or any third-party servers.

This application uses the account credentials provided by the User to request game data from MiHoYo Co., Ltd. (Shanghai)'s public API. The retrieved data is displayed locally only and is not used for any other purpose.

This application is an unofficial tool and has no affiliation with MiHoYo Co., Ltd.

The Developer does not actively collect any personally identifiable information.

### Log Data

This application generates runtime logs on the local device to assist with troubleshooting. These log files are stored only on the User's device and are not automatically uploaded to any server. Users may manually export log files from within the application to report issues to the Developer.
