# 回复语言规则

## 1. 只用中文回答

所有 assistant 回复必须用中文，包括：

- 分析、计划、总结、下一步建议、风险报告：中文。
- 面向用户提问（包括选项）：中文。
- 面向用户的项目文档和代码注释：中文。

**保持原文（不翻译）**：

- 代码、命令、文件路径。
- class / method / variable 名称、rule ID（N-1、P-3）、module ID（M1-M15）。
- 编译错误、log、stack trace、source snippet。
- 专有技术术语：ArkTS、ArkUI、hypium、hvigor、NavPathStack、@ComponentV2、AppStorage 等。
