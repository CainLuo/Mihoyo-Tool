# Widget UI 间距标注文档

> 本文档定义所有 Widget 尺寸的组件间距规范，确保实现时的一致性。

---

## 一、通用间距常量

| 常量名 | 值 (vp) | 用途 |
|-------|---------|------|
| `PAD_CARD` | 12 | 卡片内边距（四周） |
| `GAP_TIGHT` | 2 | 紧凑间距（体力数字与恢复时间之间） |
| `GAP_NORMAL` | 4 | 标准间距（游戏名与 UID 之间） |
| `GAP_MEDIUM` | 5 | 中等间距（数据行之间） |
| `GAP_SECTION` | 6 | 区块间距（头部与体力区块之间） |
| `GAP_BLOCK` | 8 | 大区块间距（体力区块与数据行之间） |

---

## 二、1×2 Widget（单游戏迷你卡片）

**尺寸**：168 × 80 vp（含 padding 168 × 56 vp 内容区）

### 2.1 布局结构

```
┌────────────────────────────────────────┐
│ PAD_CARD (12)                          │
│ ┌────────────────────────────────────┐ │
│ │ 游戏名 (12px)  GAP_NORMAL (4)  UID (10px)     │ ← 头部
│ └────────────────────────────────────┘ │
│                                        │
│ GAP_SECTION (6)                        │
│                                        │
│ ┌────────────────────────────────────┐ │
│ │ 体力数字 (24px) GAP_TIGHT (2) /max (14px) │ ← 体力行
│ └────────────────────────────────────┘ │
│                                        │
│ GAP_TIGHT (2)                          │
│                                        │
│ 恢复时间 (11px)                        │
│                                        │
│ PAD_CARD (12)                          │
└────────────────────────────────────────┘
```

### 2.2 间距明细

| 区域 | 间距 | 说明 |
|-----|------|------|
| 卡片 padding | 12vp 四周 | 外边距 |
| 游戏名 ↔ UID | 4vp | 同一行内水平间距 |
| 头部 ↔ 体力区块 | 6vp | `margin-bottom` |
| 体力数字 ↔ /max | 2vp | 水平间距 |
| 体力数字行 ↔ 恢复时间 | 2vp | 垂直间距 |

## 三、2×2 Widget 单游戏

**尺寸**：168 × 168 vp（含 padding 146 × 146 vp 内容区）

### 3.1 布局结构

```
┌────────────────────────────────────────┐
│ PAD_CARD (12)                          │
│ ┌────────────────────────────────────┐ │
│ │ 游戏名 (12px)                       │ │ ← 头部
│ │ UID (10px) GAP_NORMAL (1px)        │ │
│ └────────────────────────────────────┘ │
│                                        │
│ GAP_SECTION (6)                        │
│                                        │
│ ┌────────────────────────────────────┐ │
│ │ 体力数字 (24px) GAP_TIGHT (3) /max (14px) │ ← 体力区块
│ │ 恢复时间 (11px)                    │ │
│ └────────────────────────────────────┘ │
│                                        │
│ GAP_BLOCK (8)                          │
│                                        │
│ ┌────────────────────────────────────┐ │
│ │ 数据行 1 (11px)                    │ │ ← 额外数据行
│ │ GAP_MEDIUM (5)                     │ │
│ │ 数据行 2 (11px)                    │ │
│ └────────────────────────────────────┘ │
│                                        │
│ PAD_CARD (12)                          │
└────────────────────────────────────────┘
```

### 3.2 间距明细

| 区域 | 间距 | 说明 |
|-----|------|------|
| 卡片 padding | 12vp 四周 | 外边距 |
| 游戏名 ↔ UID | 1vp | 垂直间距（换行显示） |
| 头部 ↔ 体力区块 | 6vp | `margin-bottom` |
| 体力数字 ↔ /max | 3vp | 水平间距 |
| 体力区块内部 | 2vp | 数字行 ↔ 恢复时间 |
| 体力区块 ↔ 数据行区域 | 8vp | 大区块间距 |
| 数据行之间 | 5vp | 每行之间 |

### 3.3 星铁特殊布局

星铁的后备开拓力显示在体力区块右侧：

```
┌────────────────────────────────────────┐
│ 体力数字 (24px) GAP_TIGHT (3) /max (14px)    后备开拓力 │
│ 恢复时间 (11px)                          2400 (12px) │
│                                          ↑ GAP_TIGHT (1px) │
└────────────────────────────────────────┘
```

| 区域 | 间距 | 说明 |
|-----|------|------|
| 体力区块 ↔ 后备开拓力 | `justify-content: space-between` | 水平分散 |
| "后备"文字 ↔ 数值 | 1vp | 垂直间距 |

## 四、2×2 Widget 多游戏

**尺寸**：168 × 168 vp

### 4.1 布局结构

```
┌────────────────────────────────────────┐
│ PAD_CARD (12)                          │
│ 账号昵称 (11px)                        │ ← 头部
│                                        │
│ GAP_NORMAL (4)                         │
│                                        │
│ ┌────────────────────────────────────┐ │
│ │ 游戏色竖线 (3×height) GAP_NORMAL (8) 游戏名 (11px)  │ ← 游戏 1
│ │                                    │ │
│ │ 体力数字 (18px) /max (11px)        │ │
│ │ 恢复时间 (9px)                     │ │
│ └────────────────────────────────────┘ │
│                                        │
│ 分隔线 (1px)                           │
│                                        │
│ GAP_NORMAL (4) × 2 (上下)              │
│                                        │
│ ┌────────────────────────────────────┐ │
│ │ 游戏色竖线 (3×height) GAP_NORMAL (8) 游戏名 (11px)  │ ← 游戏 2
│ │                                    │ │
│ │ 体力数字 (18px) /max (11px)        │ │
│ │ 恢复时间 (9px)                     │ │
│ └────────────────────────────────────┘ │
│                                        │
│ PAD_CARD (12)                          │
└────────────────────────────────────────┘
```

### 4.2 间距明细

| 区域 | 间距 | 说明 |
|-----|------|------|
| 卡片 padding | 12vp 四周 | 外边距 |
| 头部 ↔ 第一行游戏 | 4vp | `margin-bottom` |
| 游戏色竖线 ↔ 内容区 | 8vp | 水平间距 |
| 两行游戏之间分隔线 | 1px + 4vp × 2 | 分隔线高度 + 上下 margin |
| 游戏名 ↔ 体力数字 | 1vp | 垂直间距 |
| 体力数字 ↔ 恢复时间 | 1vp | 垂直间距 |

### 4.3 游戏色竖线

| 属性 | 值 |
|-----|------|
| 宽度 | 3vp |
| 高度 | 父容器高度的 50%（上下各留 25%） |
| 圆角 | 2vp |
| 颜色 | 游戏主题色 |

## 六、2×4 Widget

**尺寸**：336 × 168 vp

### 6.1 布局结构

水平排列两个 168 × 168 区域，每个区域布局与 2×2 单游戏相同。

```
┌─────────────────────────┬─────────────────────────┐
│                         │                         │
│    168 × 168           │    168 × 168            │
│    (游戏 1)            │    (游戏 2)             │
│                         │                         │
└─────────────────────────┴─────────────────────────┘
```

### 6.2 间距明细

| 区域 | 间距 | 说明 |
|-----|------|------|
| 两个区域之间 | 无分隔线 | 直接拼接 |
| 各区域内部间距 | 同 2×2 单游戏 | 见第三节 |

### 7.1 布局结构

```
│ │ 游戏 3 卡片 (100×height)           │ │
│ └────────────────────────────────────┘ │
│                                        │

└────────────────────────────────────────┘
```

### 7.2 单个游戏卡片内部

每个游戏卡片内部结构与 2×2 多游戏中的单行相同。

## 八、字号规范

| 用途 | 字号 | 字重 |
|-----|------|------|
| 体力数字（大） | 24px | Bold |
| 体力数字（中） | 18px | Bold |
| 游戏名（1×2） | 12px | Bold |
| 游戏名（2×2 多游戏） | 11px | Medium |
| UID | 10px | Normal |
| /max | 14px（大）/ 11px（中） | Normal |
| 恢复时间 | 11px（大）/ 9px（小） | Normal |
| 数据行标签/值 | 11px | Normal |
| 后备开拓力标签 | 9px | Normal |
| 后备开拓力数值 | 12px | Bold |

---

## 九、颜色规范

| 用途 | 颜色 | 说明 |
|-----|------|------|
| 体力数字（0-30%） | `#ef5350` | 红色警告 |
| 体力数字（30-70%） | `#ffca28` | 橙色提醒 |
| 体力数字（70-100%） | 游戏主题色 | 正常 |
| 游戏色竖线 | 游戏主题色 | 原神蓝/星铁紫/绝区零橙 |
| 文字（主） | `rgba(255,255,255,0.8)` | 游戏名 |
| 文字（次） | `rgba(255,255,255,0.5)` | 恢复时间 |
| 文字（弱） | `rgba(255,255,255,0.35)` | UID、/max |
| 分隔线 | `rgba(255,255,255,0.08)` | 多游戏行之间 |
