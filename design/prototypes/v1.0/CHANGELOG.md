# UI 原型版本记录

## v1.0 — 2026-03-21（已确认锁定）

### 确认范围

- 角色详情页（`char-detail.html`）
- 角色卡片组件（`character-card-prototype.html`）

### 角色详情页设计规范

#### Phone 竖屏（360×780）

- 顶部：角色头像切换横条（sw 栏）
- 立绘区（260px 固定高）：图片贴右，左侧渐变遮罩，左下角角色名+等级+好感，右侧命座纵列
- 滚动区：武器行 → 属性 2 列网格 → 圣遗物 2 列网格卡片

#### Phone 横屏（780×360）

- 左侧立绘（200px 固定宽）：图片铺满，左下角文字，右侧命座纵列
- 右侧滚动区：武器行 → 属性 4 列网格 → 圣遗物 2 列网格卡片

#### 宽屏（Foldable / TripleFold / Tablet / 2in1/PC）

- 三栏等分（各 flex:1），外层 8px padding + 8px gap
- 左栏（立绘区）：
  - 背景色根据角色元素力变化（水=深蓝，雷=深紫，火=深红，风=深绿，岩=深棕，冰=深蓝灰，草=深绿）
  - 立绘 object-fit:cover 铺满整个区域
  - 左上角：角色名 + 等级/上限 + 好感
  - 左下角：命座圆点 1→6 从上到下竖排
  - 右下角：普攻/战技/爆发 3个技能图标+等级从上到下竖排
- 中栏（武器+属性）：武器图标+名称+攻击+副属性+精炼+等级+星级，下方属性列表（带基础值+加成双行）
- 右栏（圣遗物）：5条等分高度，每条左侧图标+主词条+星级+强化，右侧 2列×2行副词条
