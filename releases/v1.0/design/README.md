# UI 设计资产目录

## 目录结构

```
design/
└── prototypes/
    ├── v1.0/          # 已确认锁定版本（2026-03-21）
    │   ├── char-detail.html
    │   ├── character-card-prototype.html
    │   └── CHANGELOG.md
    └── v1.1/          # 下次改版时创建
```

## 版本管理规则

1. 每个版本对应一个独立子目录，命名格式 `vX.Y/`
2. 用户确认原型后，该版本目录**只读锁定**，不得修改
3. 改版时复制上一版本目录，在新目录中修改，并在 `CHANGELOG.md` 追加记录
4. 根目录的 `char-detail.html` 等文件是**当前工作版本**，用于迭代调试
