# 米游社数据工具箱（纯血鸿蒙版）

# 页面细节规范

## 文档版本：V1.0

## 文档类型：UI/交互实现（长什么样、怎么交互）

## 适用对象：开发、Kiro、Trae CN

## 文档说明

- 文档版本：V1.0
- 适配工具：Kiro AI IDE、Trae CN（字节系）
- 核心适配：鸿蒙全设备（手机竖屏 / 折叠屏 / 双折 / 三折 / 平板 / 鸿蒙 PC）
- 文档用途：供 AI 工具识别、开发人员落地，包含所有确认的页面细节、交互逻辑、业务规则，无冗余、无模糊，完全对齐需求共识
- 核心原则：遵循鸿蒙官方响应式布局，三套游戏角色详情独立设计，防暴力点击、合规性要求全覆盖

## 一、全局通用规则（所有页面适用）

### 1. 鸿蒙全设备自适应规范

- 布局基础：采用鸿蒙官方响应式布局体系，使用 Row/Column/Flex 弹性布局，不写死像素宽度，采用 Weight/Percentage 适配
- 导航适配：`Navigation` 组件 `NavigationMode.Auto` 自动适配，手机竖屏使用底部 TabBar，宽屏（折叠屏展开 / 平板 / PC）自动切换为左侧侧边栏 + 右侧内容分栏布局
- 内容适配：列表、卡片、网格根据屏幕宽度自动调整列数，文字、间距自动适配屏幕尺寸
- 主题适配：浅色 / 深色模式跟随系统，全设备保持一致

### 2. 刷新规则（全局统一）

- 刷新触发：页面右上角刷新按钮
- 冷却限制：两次刷新时间间隔 < 30 分钟，弹出 Dialog 提示，含"取消"和"继续刷新"两个按钮
- 刷新逻辑：刷新时按钮置灰禁用，直到刷新结果返回后恢复
- 数据处理：刷新成功后更新本地数据库，同步刷新页面；刷新失败弹出错误提示

### 3. 防暴力点击规则（所有可点击按钮适用）

- 核心原则：所有按钮点击后立即置灰禁用，等待接口返回 / 动作完成后再恢复可点击状态
- 覆盖按钮：获取验证码、登录、刷新二维码、保存 Cookie、协议确认、删除账号等所有可交互按钮
- 特殊限制：获取验证码按钮额外增加 60 秒倒计时（手机号格式合法才可点击）

### 4. 空状态 / 异常状态通用规范

- 空状态：无数据时，居中展示占位图标 + 提示文字 + 操作按钮（如有）
- 异常状态：网络失败、验证失败、数据加载失败时，展示对应提示文案 + 刷新按钮
- 加载状态：所有数据加载时，展示加载动画，不显示空白页面

### 5. 合规要求

- 首屏隐私合规：首次启动展示 `PrivacyConsentPage`（用户协议 + 隐私政策两步确认），用户同意后方可进入主页面
- 登录页协议：登录页底部固定展示"登录即表示您同意《用户协议》与《隐私政策》"，协议文字可点击，点击后打开内置 WebView 展示协议内容
- 数据安全：所有登录凭证、游戏数据、账号信息仅本地加密存储，不上传至任何第三方服务器

## 二、页面详细规范（按页面流程排序）

### 1. 启动页（Launch Page）

#### 页面基础

- 页面名称：LaunchPage
- 页面作用：应用启动时的过渡页，检查隐私协议同意状态
- 跳转规则：
  - 首次启动（未同意隐私协议）：展示 500ms~800ms 后跳转至 `PrivacyConsentPage`
  - 已同意隐私协议：展示 500ms~800ms 后直接跳转至 `MainPage`

#### 布局与样式

- 背景：纯色背景，自动适配浅色 / 深色模式
- 中央元素：居中展示 App 圆角 Logo，Logo 下方展示 App 名称
- 动画效果：轻微淡入（0.3 秒）+ 轻微缩放（从 0.9 倍放大至 1.0 倍）

### 2. 隐私合规页（PrivacyConsentPage）

#### 页面基础

- 页面名称：PrivacyConsentPage
- 进入方式：首次启动时由 LaunchPage 跳转
- 流程：两步确认
  - 步骤一：用户协议全文，滑动到底部后「下一步」按钮 Enable
  - 步骤二：隐私政策全文，滑动到底部后「同意并继续」和「不同意，退出」按钮 Enable
- 协议内容：通过 WebView 加载本地 HTML 文件（`rawfile/legal/`），根据系统语言自动选择简体中文 / 繁体中文 / 英文版本
- 不同意处理：点击「不同意，退出」调用 `terminateSelf()` 退出应用

### 3. 主页面（Main Page）

#### 页面基础

- 页面名称：MainPage
- 页面结构：底部 TabBar（手机）/ 左侧侧边栏（宽屏）+ 内容区，TabBar 固定 3 个选项
- 默认选中：Tab1（首页）

#### 底部 TabBar（3 个选项，按顺序）

1. Tab1：首页（图标 + 文字，默认选中）
2. Tab2：角色（图标 + 文字）
3. Tab3：我的（图标 + 文字）

### 4. Tab1：首页（Home）

#### 页面基础

- 页面名称：Home
- Navigation 标题：首页
- 进入逻辑：优先判断本地是否有已添加的米游社账号，分两种状态展示

#### 状态 1：无账号（Placeholder）

- 居中展示占位图标 + 提示文字 + "去绑定账号" 按钮，点击跳转至登录页

#### 状态 2：有账号（战绩列表）

- 布局：按米游社账号分组展示，每组为一个账号，组内展示该账号下所有游戏的战绩卡片
- 右上角：刷新按钮（遵循全局 30 分钟冷却规则）

#### 游戏战绩卡片内容

- 通用内容：游戏图标、游戏昵称、游戏 UID
- 原神卡片：原粹树脂（当前 / 封顶）、回满时间、洞天财瓮（当前 / 封顶）、每日委托完成状态、参量质变仪状态、探索派遣状态
- 星穹铁道卡片：开拓力（当前 / 封顶）、回满时间、后备开拓力、每日实训（当前 / 封顶）、历战余响（当前 / 封顶）、模拟宇宙积分（当前 / 封顶）
- 绝区零卡片：电量（当前 / 封顶）、回满时间、活跃度（当前 / 封顶）、录像店状态、刮刮卡状态

#### 交互规则

- 点击单个游戏战绩卡片：跳转至该游戏的便笺详情页

### 5. Tab2：角色列表页（Characters）

#### 页面基础

- 页面名称：Characters
- Navigation 标题：角色
- 进入逻辑：与首页完全一致，无账号展示同款 Placeholder 页面

#### 有账号状态：页面结构

- 顶部：游戏 Tab 栏（GameTabBar），横向排列各游戏 Tab，点击切换当前展示的游戏角色列表
- 右上角：
  - 刷新按钮：刷新当前账号当前游戏的角色数据（遵循全局 30 分钟冷却规则）
  - 账号切换按钮（多账号时显示）：点击弹出账号选择 Menu，切换当前展示的账号
- 内容区：角色列表，仅显示「当前选中账号 × 当前选中游戏」的角色

#### 角色列表展示规则

- 布局：双列网格，宽屏自动增加列数
- 单角色卡片内容：角色头像、角色名称、角色星级、角色等级、武器 / 光锥简要信息、命座 / 星魂数量

#### 交互规则

- 游戏 Tab 切换：切换游戏后，实时刷新角色列表
- 点击角色卡片：跳转至该角色的详情页

### 6. Tab3：我的页（My）

#### 页面基础

- 页面名称：My
- Navigation 标题：我的
- 布局：纵向列表，分 4 个 Section

#### Section 1：账号管理

- 内容：已添加账号列表，每行显示账号昵称 + 米游社 ID
- 交互：点击账号行跳转至账号详情页（AccountDetail）；底部有「添加账号」按钮，点击跳转至登录页

#### Section 2：外观设置

- 内容：主题切换（跟随系统 / 浅色 / 深色），三个选项横向排列，当前选中项高亮
- 交互：点击选项立即切换主题，全局实时生效

#### Section 3：通知设置

- 内容：通知设置入口行
- 交互：点击跳转至通知设置页（NotificationSettings）

#### Section 4：关于

- 内容：版本号、GitHub 链接、许可证等信息行
- 交互：点击 GitHub / 许可证行打开对应链接

## 二级页面：角色详情页（三款游戏独立结构）

- 进入方式：角色列表页点击角色卡片

3. 音擎区域：音擎图标 + 名称 + 等级 + 精炼等级 + 主属性

## 二级页面：登录页（Login）

### 页面基础

- 页面名称：Login
- 进入方式：首页 / 角色页空状态点击"去绑定账号"；我的页点击"添加账号"
- 页面结构：上中下三段（顶部品牌区、中间登录方式切换区、底部协议区）

### 顶部品牌区

- 内容：App 圆角图标（居中）+ App 名称

### 中间登录方式切换区

- 切换方式：Tab 切换，3 种方式互斥
- 方式 1：手机号登录（**仅 mock / debug / internal 包含，release 包不显示**）
  - 表单：11 位手机号输入框 + 短信验证码输入框
  - 按钮：获取验证码（60 秒倒计时）、登录
- 方式 2：扫码登录
  - 内容：米游社登录二维码（居中）+ 提示文字
  - 按钮：刷新二维码
- 方式 3：手动填写 Cookie
  - 表单：多行输入框（提示"请粘贴米游社登录 Cookie"）
  - 按钮：保存并校验 Cookie（Cookie 为空时禁用）

### 底部协议区

- 内容："登录即表示您同意《用户协议》与《隐私政策》"，协议文字可点击
- 交互：点击协议文字 → 打开 WebViewPage 展示对应协议内容

### 登录结果处理

- 登录成功：保存账号信息到本地数据库，跳转至 AccountDetail 页，并触发后台数据同步
- 登录失败：弹出错误提示，恢复按钮可点击状态

## 四、术语定义

- 米游社账号：用户注册的米哈游官方账号
- 登录凭证（Cookie）：米游社登录后生成的身份验证信息，仅本地加密存储
- mock 构建：数据来自本地预设 JSON 文件，不请求真实接口
- release 构建：上架包，数据来自米游社真实接口，移除手机号登录
- 多账号隔离：多个米游社账号的游戏数据完全独立，互不干扰
- 防暴力点击：按钮点击后立即置灰禁用，避免连续点击

## 五、范围界定

### V1.0 必做

- 所有页面详细规范中描述的功能、交互、适配规则
- 三种登录方式（release 包仅扫码 + Cookie）、防暴力点击、刷新冷却、合规协议
- 三款游戏的便笺详情、独立角色详情页
- 全设备自适应、多语言、多主题切换

- 游戏数据修改、作弊等违规功能
- 云端存储、数据同步、社交分享（V2.0 新增）
- 角色练度统计、数据导出、圣遗物评分（V3.0 新增）
- 非米哈游旗下游戏的数据查询
